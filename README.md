# Wandr

Open three PowerShell terminals in the project folder and run one block in each.

## GraphHopper

```powershell
.\backend\start_graphhopper.ps1
```

## Backend

```powershell
cd backend
.\.venv\Scripts\Activate.ps1
python main.py
```

## Frontend

```powershell
npm run dev
```

Open `http://localhost:3000`.
